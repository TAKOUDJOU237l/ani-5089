Ma sensibilité : 0.002 radian par compte du capteur (la constante SENSIBILITE de derive.cpp), gardée pour toute la mesure.

Vitesse de dérive : -1.79 deg/s
Je l'ai calculée sur deux lignes éloignées de derive.txt : A = « t = 29.0 s, lacet = -2.4 deg » et B = « t = 46.0 s, lacet = -32.8 deg ». Calcul : (-32.8 - (-2.4)) / (46.0 - 29.0) = -30.4 / 17.0 = -1.79 deg/s. Le signe négatif veut dire que le lacet diminue : la tête tourne dans le sens négatif.

D'où vient ce chiffre : de ce que la tête ajoute brut × sensibilité à son lacet à chaque image. Sur derive.txt, la colonne brut vaut -1 à toutes les lignes de 29.0 s à 46.0 s. La colonne images donne la cadence : (552 - 287) / (46.0 - 29.0) = 265 / 17.0 = 15.6 images par seconde. Calcul : -1 × 0.002 rad/compte × 15.6 images/s = -0.0312 rad/s, soit -0.0312 × 180 / pi = -1.79 deg/s. C'est le même nombre que celui mesuré sur les deux lignes. La vitesse dépend donc de la cadence de ma machine : avec la même valeur de brut, à 60 images par seconde, la tête tournerait à environ 6.9 deg/s.

Dans les deux relevés, c'est la même chose qui arrive : ma tête ajoute brut x 0.002 rad à son lacet à chaque image, et NkInput.MouseRawDeltaX() rend le déplacement brut que garde le module d'entrées, donc la valeur du dernier événement, et non un déplacement nouveau ; mon code la relit à chaque image comme si elle l'était. Elle s'arrête quand cette valeur gardée est 0, elle dérive quand elle ne l'est pas. Ce qui change juste avant, d'après les lignes : dans le cas qui reste à 0, les dernières valeurs sont 6, 1, 3 puis 0, un mouvement qui s'éteint ; dans le cas qui reste à -1, la valeur d'avant est 1 puis -1, un tout petit mouvement.
