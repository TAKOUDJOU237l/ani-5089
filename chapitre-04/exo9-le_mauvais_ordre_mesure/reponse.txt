Facteur : chaque coordonnée de la translation est multipliée par l'échelle de son axe. Pour le mur du fond, la translation est (0 ; 1,25 ; -2) et l'échelle (4 ; 2,5 ; 0,1). Le facteur vaut donc 4 sur x, 2,5 sur y et 0,1 sur z. Sur x la translation est nulle, le facteur ne se voit pas. Sur y, 1,25 devient 3,125. Sur z, -2 devient -0,2. Le centre du mur passe de (0 ; 1,25 ; -2) à (0 ; 3,125 ; -0,2).

Pourquoi : les matrices ne commutent pas, et Translate * Scale se lit de droite à gauche. Avec Translate * Scale, le cube unitaire est d'abord étiré en un mur de 4 sur 2,5 sur 0,1 centré à l'origine, puis la translation le déplace de (0 ; 1,25 ; -2). Le centre arrive exactement là où on l'a demandé. Avec Scale * Translate, c'est la translation qui passe en premier, puis l'échelle multiplie les coordonnées de tous les points, y compris le déplacement qu'on vient d'ajouter. L'échelle attrape donc aussi la translation. Aucun message d'erreur n'est affiché : le programme compile, le mur est dessiné, mais à une autre place.
